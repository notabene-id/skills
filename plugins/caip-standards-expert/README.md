# CAIP standards expert

A Claude Code plugin with one skill, `caip-standards-expert`, for Chain Agnostic Improvement Proposals (CAIPs) and
the CASA namespace registry. Use it when parsing or constructing chain-agnostic identifiers for blockchains (CAIP-2),
accounts (CAIP-10) and assets (CAIP-19), working with namespace profiles, or preparing a new namespace submission.

## Install

```text
/plugin marketplace add notabene-id/skills
/plugin install caip-standards-expert@notabene-skills
```

## Contents

- `skills/caip-standards-expert/SKILL.md`: the skill
- `skills/caip-standards-expert/references/`: CAIP-2, CAIP-10 and CAIP-19 specs, namespace profiles, submission guide
