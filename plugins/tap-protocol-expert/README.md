# TAP protocol expert

A Claude Code plugin with one skill, `tap-protocol-expert`, for the Transaction Authorization Protocol (TAP) and its
improvement proposals (TAIPs). Use it when designing, building or reviewing TAP-based flows: TAP messages over
DIDComm, transfers and payments, authorization, agent and party fields, policies, and the TypeScript, Rust and Go
libraries.

## Install

```text
/plugin marketplace add notabene-id/skills
/plugin install tap-protocol-expert@notabene-skills
```

## Contents

- `skills/tap-protocol-expert/SKILL.md`: the skill
- `skills/tap-protocol-expert/references/`: TAIP catalog, message types, agent and party fields, language guides
